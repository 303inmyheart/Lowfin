# 1.1.2 — home return selection and optional precache screen-awake behavior

Settings / Library and Cache now contains a reversible Prevent sleep during precache switch (default off), with EN/DE labels and a scope hint. MainActivity sets keepScreenOn on its current root only while enabled and a full baseline is syncing or CacheChanges is actively handling queued artwork. The existing two-second status update applies/removes it; idle long polling does not hold the screen awake. All MainActivity screens use this root, so settings and browsing remain covered. The setting does not clear player/trailer window flags and adds no wake-lock permission or global TV setting. Android honors this while the app window is visible; leaving the app, explicit power-off and independent hardware sleep timers are not overridden. Official API guidance: https://developer.android.com/develop/background-work/background-tasks/awake/screen-on

Home screen history now records a data/layout-only HomeAdapter.State before opening details or a full shelf list: semantic shelf keys, rows/labels, per-shelf selected columns, horizontal layout state, selected media ID and explicit More-card identity. It retains no View/RecyclerView/Activity hierarchy. Restore only compatible shelf-key configurations. Render the snapshot immediately, reveal/position its saved row and focus its selected card rather than allowing cached Continue data to reset focus to the first row. A cold home screen still selects its normal first row/card.

On immediate return, genre/recommendation selections keep their previous random ordering and restart their normal two-minute refresh cooldown instead of rerandomizing immediately. Resume and Next Up still refresh independently as in 1.1.1. Background batched local hydration applies updated metadata/Companion state to saved rows without changing order; screen generation, network freshness and snapshot-identity guards reject late old data. This avoids losing plugin updates received while details were open. Focused row refreshes resolve the selected media ID before falling back to a clamped column if it disappeared; More remains More after a size change.

Regression coverage opens details from a scrolled recommendation row, a scrolled genre row with animation enabled, and opens/returns from a More card. Assert same row/card, horizontal position (allowing small native focus-visibility adjustment with animated zoom), fresh local metadata and ID-based focus after reordering. Wake tests cover default-off, enabled active baseline, completed work, active incremental artwork and switching off. Existing rapid-navigation, single-shelf, first-entry, library-return, cache and player tests remain in the complete suite.
