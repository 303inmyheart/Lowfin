# Live TV current programme (1.2.16)

Channel cards reuse ConfirmPress: short OK opens playback, held OK opens the current-programme dialog and consumes the gesture so release cannot start playback. Requests are scoped to the current user and channel, bounded to one programme with start <= now and end > now. Returned channel IDs and timestamps are checked again. No guide or stream is loaded. The dialog shows local start/end times, title, episode title and description; missing guide data and network failures have distinct EN/DE messages. Late responses cannot update a dismissed dialog or another account. Existing DialogViewport bounds and scrolling apply; populated content is refitted after the asynchronous response.

Sidebar availability uses one channel without images in a background request with an 8-second deadline. The last successful boolean is stored in the account-scoped library state. Successful empty results and access-denied/not-found hide the entry; transient failures retain the prior result. Refresh happens at startup/account change and on resume after at least one minute, without polling while idle.

Native Jellyfin 12.2 API XML confirms the date filters on GetProgramsDto. Mock server tests cover bounded authenticated queries, no-channel results, access denial, transient failures and rejection of ended/future/wrong-channel programmes. Existing long-press regression tests remain in the full suite. Latest user instruction: build only; do not install or launch on any TV. 459 client tests and release lint passed; 465 English/German resource entries covered.
